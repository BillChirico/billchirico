## 🚀 Volvox — My Software Studio

> _Building software that matters, one app at a time._

[**Volvox**](https://volvox.dev) is my software studio where we build apps that solve real problems we've encountered. No venture capital, no feature bloat—just thoughtful software for people who need it.

### 📱 Apps

**[Sobers](https://sobers.app)** · _Sobriety Companion_

Pairs sponsors with sponsees, tracks sobriety milestones, and sends check-ins for 12-step programs. Recovery is hard enough without fighting bad software—built because the existing options felt like afterthoughts.

**[Decision Jar](https://decisionjar.app)** · _Stop Overthinking & Just Shake_

For those who've spent 20 minutes deciding where to eat. Add your options, shake the jar, and let fate decide. Sometimes you just need an app to tell you what to do.

### 🎓 Volvox Community

Volvox is also a **programming learning community** where experienced developers mentor folks breaking into the industry. Code reviews, career advice, pair programming sessions—the stuff Stack Overflow and Claude can't give you.

Whether you're shipping your first PR or your hundredth, there's a seat at the table.
